# F1.5 결과 — Ω 보정·비중 상한·δ 민감도 (US · gpt-oss-20b · 프롬프트 A)

실행 2026-10-10, CPU만 사용(F1에서 받은 view 재사용, 822+30개 작업 약 5분). 코드: `src/03_backtest.py`, 표·그림 생성 `src/92_paper_assets.py`. 결과: `results/US/gptoss20b_A/`, 논문 표 `paper/fi/tables/`.

## 이전 문제 → 변경
F1에서 판정 기준 (b) "흩어짐 Ω가 상수·He–Litterman Ω보다 낫다"가 실패했다(경험적 −2.02, 상수 −1.32, HL −0.87). 회의적 독자는 "비중 쏠림(최대 91%)과 보정 안 된 Ω 탓"이라고 반박할 수 있다. 그래서 같은 q에서 다음을 추가했다.
- **수준 맞춤(level-matched):** 매 시점 Ω의 평균을 τ·평균(Σ_ii)에 맞춘다. τ는 Ω 전체 수준을 흡수하지만(μ_BL(cτ, cΩ) = μ_BL(τ, Ω)) 분기 안에서 시점마다 바뀌는 수준은 흡수하지 못하므로, 그것을 없애고 **모양만** 비교한다.
- **비중 상한 10%.**
- **선형 보정 Ω:** Ω = a + b·s², 과거 쌍으로 (오차² − 운) 를 s²에 회귀. 운을 뺀 view 오차를 직접 겨냥.
- **δ 민감도:** 1.5 / 2.5 / 3.5 / 252일 추정.
- **진단:** q의 공통 수준 편향 제거(q − 평균 q + 평균 Π).
- 보정 지표: 변동성 표준화 순위상관, 부분상관, 운 포함 커버리지(50/80/95%), run_meta.json(리비전).

## 결과
| Ω (Sharpe) | 그대로 | 수준 맞춤 | 상한 10% | 수준 맞춤+상한 |
|---|---|---|---|---|
| 경험적 s² | −2.02 | −1.46 | −0.28 | −0.34 |
| 상수 | −1.32 | −0.49 | **0.31** | 0.15 |
| 섞음 | 0.48 | −0.50 | −0.12 | −0.07 |
| He–Litterman | −0.87 | −0.87 | 0.23 | 0.23 |
| 등위 보정 | −1.45 | −0.92 | −0.30 | −0.09 |
| 선형 보정 | −1.81 | −1.00 | −0.25 | −0.07 |
| 경험적 − 상수 | −0.70** | −0.97** | −0.59** | −0.49** |
| 경험적 − HL | −1.15*** | −0.58 | −0.51** | −0.57*** |

- **(b)는 네 설정 모두에서 실패.** 상한·수준 맞춤은 손실을 줄이지만 순서는 그대로다. 보정은 경험적 Ω보다 낫지만(선형은 4개 설정 모두) 상수·HL을 넘지 못한다.
- **δ는 결론에 영향 없음.** view가 있는 BL의 Sharpe 변화 ≤ 0.04. 252일 추정 δ는 3.3~18.0(중앙값 5.6)이고 이 기간엔 음수가 없었다. view 없는 사전분포만 −0.26~−0.04로 움직인다. τ walk-forward가 사전분포와 view의 균형을 다시 맞추기 때문.
- **q 중심화 진단:** 경험적 −2.02 → −2.01. 공통 낙관 편향(평균 q 0.20%/일 vs 실현 0.08%)은 원인이 아니다.
- 거래비용 0~25bp에서 순서 불변. 동일가중(0.86)을 넘는 BL+LLM 조합은 없다.

## 왜 정보가 있는데 손해인가 (논문 §5.4)
- s² 십분위 1→10: s²는 **121배**, 실제 제곱오차는 **4.0배**, 운(변동성)은 3.2배 증가. 같은 시점 안 P90/P10: s² 22배, 변동성 5.6배.
- 순위는 대체로 맞지만 크기가 약 30배 과장되어 있다. Ω⁻¹이 가중치이므로, 경험적 Ω는 흩어짐이 작은 소수 view를 백 배 더 믿어 포트폴리오를 쏠리게 한다. q에 예측력이 없으니 쏠림은 분산만 키운다.
- 흩어짐은 최근 움직임의 크기를 따른다(변동성 표준화 후 |과거 10일 수익|과의 순위상관 0.52). 큰 움직임을 외삽할 때 자기 답이 더 갈린다.
- 답이 이산적이다: 20개 중 평균 10개만 서로 다르고, 최빈값이 29%를 차지하며, "0.05"가 전체 답의 10%. 흩어짐이 작다는 것은 확신보다 같은 어림수를 반복했다는 뜻인 경우가 많다.

## 해석
- 판정: (a) 통과, (b) 실패가 강건하다. "LLM 반복 추출 흩어짐 → Ω" 프레임워크는 현재 입력(숫자만)에서는 결정 가치가 없고, 원 연구의 성과는 수정된 설계에서 재현되지 않는다.
- 논문은 negative result + 평가 프로토콜(잡음 분해, τ–Ω 수준 비식별성, HL 기준, out-of-sample τ) + "순위 정보 ≠ 결정 가치" 메커니즘으로 쓸 수 있다(`paper/fi/`, 초안 작성됨).
