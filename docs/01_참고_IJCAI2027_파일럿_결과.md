# 0단계 파일럿 결과 (2026-10-09)

기존 view(prompt 4, 8개 모델, 2024-06~2025-06)를 수정된 파이프라인(`src/blx/`, `src/90_pilot_stage0.py`)으로 재평가한 것. 목적은 새 파이프라인 검증과 효과 크기 가늠이며, 이 결과는 논문에 쓰지 않는다(모델 컷오프가 테스트 기간 이전임을 문서로 보일 수 없고, 유니버스가 사후 정보). 수정 내용: Σ 126일 Ledoit–Wolf, δ=2.5, 시점 시가총액 w_m, 13주 T-bill, Ω는 N−1 분산+하한, τ는 검증 Sharpe로 log 그리드(1e-3~10)에서 선택.

## 1. 이전 문제 → 변경 → 결과
| | |
|---|---|
| 이전 문제 | Σ 특이(2주 창), δ 부호 반전, 사후 시가총액, 원고–코드 불일치. 리뷰어: Ω ablation·강한 baseline·유의성 검정 없음 |
| 변경 | 위 수정 + Ω 5변형 + baseline 6종 + 블록 부트스트랩 + N 민감도 + 보정 측정 |
| 새 실험 | 모델 8 × Ω 5 × τ 13(검증) → 테스트; 추가 민감도 152건. 실행 1분 15초(24 프로세스) |

## 2. 결과
### 2.1 수정 후 EAAI 효과는 사라진다
- 테스트 Sharpe(연율, 비용 10bp): EW 0.93, 시가총액 0.59, MVO(126일 평균) 1.52, 사전분포만 BL −0.31.
- BL-경험적 Ω: gemma −0.16, gpt −0.02, gpt-4.1 −0.13, **gpt-4.1-mini 0.88**, gpt-4o 0.13, llama −0.12, o3 0.18, qwen −0.04. EAAI 원고의 BL-Llama 1.23, BL-Qwen 1.06은 재현되지 않는다.
- 블록 부트스트랩(2,000회, 블록 10일): BL-경험적 vs EW의 Sharpe 차이는 8개 모델 모두 음수이고, 유의한 것은 llama(−1.05, p=0.036)뿐. BL-경험적 vs 상수 Ω, vs shuffle Ω, 보정 vs 상수 — **모두 p>0.1**. Ω의 모양이 성과에 주는 효과를 이 데이터로는 검출할 수 없다.
- 검증 기간(3개월, 7 리밸런싱)에서 고른 τ는 거의 모두 그리드 최소값 1e-3 → 사전분포가 지배 → 모든 BL이 최소분산 포트폴리오에 수렴(최대 비중 0.13, 테스트 Sharpe ≈ 사전분포). 검증 기간의 조정장(2024-08)이 저변동 포트폴리오에 유리했기 때문. **3개월 검증은 τ 선택에 부족하다.**
- 진단용 테스트 τ 스윕(선택 절차 아님): 보정 Ω는 τ=0.1에서 gpt-4.1-mini 0.51, gpt-4o 0.51, llama 0.20으로 상수 Ω(−0.47, 0.15, −0.03)보다 높다. 모양 정보가 전혀 없지는 않지만, 사전에 고를 수 없으면 쓸 수 없다.

### 2.2 q는 모멘텀이다
| 모델 | Spearman(q, 과거 10일 평균수익) | Spearman(q, 다음 10일 평균수익) |
|---|---|---|
| gemma 0.79 · gpt 0.91 · gpt-4.1 0.90 · gpt-4.1-mini 0.88 · gpt-4o 0.89 · llama 0.72 · o3 0.83 · qwen 0.75 | | 0.01–0.04 |

숫자만 입력하면 모든 모델의 평균 예측은 **입력 창의 평균수익률을 거의 그대로 되돌려 준다.** 예측력(다음 기간과의 순위 상관)은 0에 가깝다. 상위 10종목 EW(llm_topk)가 0.85–1.33으로 EW를 이기는 것은 이 기간에 모멘텀이 통했기 때문이고(MVO-126일도 1.52), LLM의 기여가 아니다. **리뷰어 R1.2·R3⑤("왜 LLM인가")에 대한 답은 "숫자만 주면 LLM은 모멘텀 변환기"다.**

### 2.3 분산에는 약한 모양 정보가 있고, 수준은 과신이다
| 모델 | Spearman(s², 제곱오차) 테스트 | 시점 내 양수 비율 | 95% 커버리지 | PIT KS |
|---|---|---|---|---|
| gemma | −0.02 | 0.32 | 0.62 | 0.31 |
| gpt(4o-mini) | 0.24 | 0.84 | 0.32 | 0.37 |
| gpt-4.1 | 0.25 | 0.95 | 0.12 | 0.48 |
| gpt-4.1-mini | 0.28 | 0.89 | 0.15 | 0.43 |
| gpt-4o | 0.31 | 0.95 | 0.24 | 0.24 |
| llama | 0.18 | 0.84 | 0.68 | 0.18 |
| o3 | 0.23 | 0.89 | 0.28 | 0.28 |
| qwen | 0.11 | 0.63 | 0.19 | 0.19 |

- 모양: GPT 계열과 o3는 분산이 큰 종목일수록 오차가 큰 경향이 **시점의 84–95%에서** 나타난다(ρ≈0.25). gemma는 없음, qwen·llama는 약함. 분산이 순수 잡음은 아니다.
- 수준: 명목 95% 구간의 실제 커버리지가 12–68%. API 모델은 답이 거의 동일해 분산이 극히 작다(gpt-4.1: 12%). 반복 추출 분산을 그대로 Ω로 쓰면 view를 과신한다. R1 조사의 CP-LLM(커버리지 0.78)보다 더 나쁘다.
- 보정 Ω(검증 300쌍 isotonic)는 테스트에서 상수 Ω와 구별되지 않는다. 300쌍으로는 모양을 안정적으로 추정하지 못한다.

### 2.4 N은 100이 필요 없다
- 보정 지표(ρ, 커버리지)는 API 모델에서 N=10부터, llama·gemma에서 N=50부터 N=100과 같다. API 모델은 서로 다른 답이 몇 개 없어서 N을 늘려도 정보가 늘지 않는다.
- 포트폴리오 Sharpe도 N=20 이후 N=100과 같다(seed 3개 평균).
- → 주 실험 N: 로컬 50, API 20. **API 모델은 반복 추출보다 logprob 분포가 더 나은 신호일 가능성** — 축 1에서 확인.

### 2.5 민감도
- δ 추정(252일) vs 고정 2.5, Σ 표본 vs Ledoit–Wolf: Sharpe 차이 ±0.3 이내, 결론 불변.

## 3. 해석과 남은 질문
- 숫자만 주는 설계에서 LLM은 모멘텀 프록시이고 분산은 과신이다. 이것이 새 설계의 출발점이자 논문의 첫 결과(negative)가 된다.
- 남은 질문: (1) 텍스트를 주면 q가 모멘텀에서 벗어나고 예측력이 생기는가, 분산–오차 정합이 올라가는가. (2) logprob·verbalized·패러프레이즈 신호는 분산보다 나은가. (3) 검증 기간을 6개월 이상으로 늘리면 τ와 보정 매핑이 안정되는가.

## 4. 다음 결정(설계 반영, `ideation/02` 수정)
- **모멘텀 baseline 필수**: 과거 10일 평균을 q로 쓰는 BL과 상위 k 모멘텀 포트폴리오. LLM 조건은 이것을 이겨야 한다.
- 검증 기간 2025-01~06(12 리밸런싱), 테스트 2025-07~2026-09(32). 모든 주 실험 모델의 컷오프가 2025-01 이전이므로 검증도 컷오프 이후다.
- N 로컬 50, API 20. 예산 재산정: API 비용 약 1/5.
- 축 1에 "API 모델의 반복 추출은 사실상 결정적" 현상을 기록하고 logprob 분포를 주 신호 후보로.

## 가이드 점검
- **한 문장 주장(이 파일럿이 답하는 것):** 숫자만 입력한 LLM 수치 예측은 모멘텀의 변환이고 그 반복 추출 분산은 과신이지만 오차와 약한 순위 정합이 있다.
- 원칙 4(주장을 검증하는 실험): 강한 baseline(MVO·모멘텀 top-k)·ablation·부트스트랩을 넣음 → 충족. 원칙 5(leakage): 파이프라인은 수정했으나 모델 컷오프·유니버스는 구 설계 그대로 → 미충족(이 결과를 논문에 쓰지 않는 이유). 원칙 6(negative result): EAAI 효과 소멸과 q=모멘텀을 그대로 기록 → 충족. 원칙 7: 코드·설정 `results/stage0/config.json` → 충족. 원칙 10: 보고 형식 → 충족.
- 세 질문: 주장은 위 한 문장. 실험이 검증하는가 — 모멘텀 상관과 부트스트랩이 직접 검증. 회의적 독자 — "기간이 9개월, 모멘텀 장세"라는 반론이 가능하고, 그래서 새 설계에서 기간을 15개월로 늘리고 모멘텀 baseline을 둔다.
