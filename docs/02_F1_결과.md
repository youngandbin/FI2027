## 근본 원인: q 자체에 정보가 없음

- Spearman(q, 과거 10일 수익률) = **0.96**, Spearman(q, 다음 기간 수익률) = **0.017**. 숫자만 주는 프롬프트에서 LLM 평균 view는 사실상 단기 모멘텀이다 (IJCAI 파일럿 0.72–0.91보다 더 강함).
- 같은 신호를 쓰는 mom_bl도 Sharpe −1.65로 실패. 2024-09 ~ 2025-12 미국 대형주의 2주 단위에서는 단기 반전이 우세해 모멘텀 view가 손해를 본다.
- BL 계열 최대 비중이 0.65–0.91로 쏠림이 크다. 확신이 큰 view가 틀린 방향이면 손실이 커지므로, 경험적 Ω(작은 s²=높은 확신)가 가장 크게 손해를 본다. τ 경로도 10 → 0.001로 크게 흔들렸다.

## 불확실성(Ω) 쪽 관찰

| 지표 | 값 |
|---|---|
| 평균 s² (view 흩어짐) | 5.2e-6 |
| 평균 운(σ²/h) | 4.6e-5 |
| 평균 제곱오차 | 5.0e-5 |
| 95% 적중률: s²만 / s²+운 / 운만 | 36% / 92.8% / 91.3% |

- 오차의 약 90%는 보유 기간의 운이고, LLM 흩어짐은 그 1/9 수준이다. s²를 더해도 적중률은 91.3% → 92.8%로 조금만 오른다.
- 즉 흩어짐에는 변동성으로 설명되지 않는 정보가 실제로 있지만(t=4.27), 보정 없이 Ω로 쓰면 확신이 약 10배 과대하다. 설계 §6.0의 판단과 일치한다.

## 반복 횟수

N=5, 10, 20의 지표가 거의 같다 (Spearman 0.15–0.19, 적중률 31–36%). 흩어짐 순위 정보는 N=5–10에서 포화된다. 이후 모델 확장 시 N=10이면 충분하다.

## 다음 결정에 필요한 선택지

1. **q 개선 없이 모델만 늘리기**: 권하지 않음. q≈모멘텀 문제는 모델이 아니라 입력(숫자만) 때문이다.
2. **프레임워크 주장을 "측정 도구"로 좁히기**: (a)의 결과(흩어짐이 변동성 이상의 오차 정보를 가짐, 단 10배 과신)를 중심으로, 보정 Ω (선형·등위 보정 + 운 항)과 쏠림 제한(종목당 10%)을 넣어 재평가. GPU 추가 사용 없이 가능.
3. **q에 정보를 넣기**: 뉴스·공시 텍스트 입력은 IJCAI 축과 겹친다. FI에서 하려면 IJCAI와의 경계(설계 §9)를 다시 정해야 한다.
