# 03. Financial Innovation 트랙: WRDS 데이터로 기존 연구 재검증 (2026-10-09)

사용자 제안(2026-10-09): IJCAI 포지셔닝과 별개로, 기존 연구(LLM 반복 추출 → BL view·Ω)를 **데이터·모델을 바꿔** 다시 돌려 살릴 수 있는지 본다. 살아나면 Financial Innovation(Springer, 금융 저널)에 낸다. 이 문서는 그 트랙("F 트랙")의 설계다. IJCAI 트랙(`02`)과 코드·데이터 수집기를 공유한다.

## 요약
- **데이터:** `data/wrds.zip` = CRSP(미국 S&P 500) + Compustat Global(KOSPI 200, Nikkei 225, DAX)의 일별 데이터, 2000-01~2025-12-31, **시점별 지수 편입 기간 포함**. 총수익률·시가총액·회사명이 있다. yfinance 데이터의 생존편향·사후 시가총액 문제가 데이터 자체로 해결된다.
- **유니버스:** 리밸런싱 시점마다 "그 날짜의 지수 구성종목 중 그 날짜 시가총액 상위 50"(DAX는 40 전부). 시점 기준 동적 유니버스.
- **기간:** 모델 컷오프(≤2024-08)와 데이터 끝(2025-12-31)에 끼여 **2024-09-01~2025-12-31(16개월)**. 2024-09~12는 τ 초기 튜닝용, 보고 구간은 2025-01~12. 시장 4개 × 리밸런싱 약 26회 = 약 100회의 독립적 결정.
- **모델:** 컷오프가 문서화된 신형만. API: GPT-5-mini, GPT-4.1-mini. 로컬: Gemma 3 27B(, Llama 3.3 70B). N=20(API는 10도 가능).
- **솔직한 예상:** 파일럿에서 gpt-4.1·gpt-4o·o3도 숫자만 주면 모멘텀 변환기였다(순위 상관 0.83–0.91). 모델을 바꿔도 이 구조는 안 바뀔 가능성이 크다. 그래서 **F1(미국·모델 1개·N=10, 약 $5)로 go/no-go를 먼저 판정**하고, 통과하면 4개 시장으로 간다. 살아날 경우의 논문 기여는 "다중 시장에서 반복 추출 분산 Ω가 관행적 Ω보다 낫다"이지 "LLM이 수익을 낸다"가 아니다.

## 1. 데이터 (`data/wrds.zip`)

- 편입 기간 `member_start`/`member_end`로 각 날짜의 구성종목을 복원한다(확인: 2024-06·2025-06·2025-12에 503/200/225/40).

- 시장 지수 수익률은 구성종목 시가총액 가중으로 계산한다(별도 지수 파일 없음).
- 비미국 시장은 LLM 프롬프트에 ticker 대신 회사명(영문)·ISIN·국가를 준다. 환율은 쓰지 않는다(각 시장을 현지 통화로 따로 평가).

## 2. 유니버스
- **동적·시점 기준:** 리밸런싱 날짜 t마다 (i) t에 지수에 속하고 (ii) t 기준 시가총액 상위 50(미국·한국·일본), DAX는 40 전부. 편출·상장폐지는 다음 리밸런싱에서 자동으로 빠진다.
- BL은 시점마다 Σ·Π·w_m을 다시 계산하므로 유니버스 변화에 문제가 없다. 신규 진입 종목은 그 시점에 view를 추가로 뽑는다(호출 수 소폭 증가).
- 비교용으로 "2024-08-30 시점 고정 유니버스"도 돌려 결과 차이를 부록에 적는다.

## 3. 기간
| 제약 | 값 |
|---|---|
| 데이터 끝 | 2025-12-31 (WRDS) |
| 모델 컷오프(문서화, R3) | GPT-4.1-mini 2024-06-01, GPT-5-mini 2024-05-31, o4-mini 2024-06-01, Gemma 3 2024-08, Llama 3.3 2023-12 |
| → OOS 가능 구간 | **2024-09-01~2025-12-31** (리밸런싱 2주, 시장당 약 34회) |

- **τ 선택:** 고정 검증/테스트 분할 대신 **walk-forward**. 2024-09~12를 초기 튜닝 창으로 두고, 이후 분기마다 그때까지의 모든 OOS 데이터(확장 창)로 τ를 다시 고른다. 파일럿에서 3개월 고정 검증이 τ를 극단값으로 보냈던 문제를 완화한다. 고정 분할(검증 2024-09~12 / 테스트 2025-01~12)은 강건성으로 병기.
- **보고 구간:** 2025-01-01~2025-12-31, 시장 4개 → 약 100회 결정. 2025-04 관세 충격이 들어 있어 하락장 구간도 포함된다.
- Gemini 2.5(컷오프 2025-01)는 2025-02 이후로만 쓸 수 있어 주 실험에서 뺀다.
- Σ 추정은 2000년부터 데이터가 있으므로 126일 창이 처음부터 확보된다.

## 4. 모델과 반복 횟수
| 모델 | 컷오프 | 실행 | 비용(시장 4 × 종목 50 × 34회 × N=20 ≈ 136k 호출, 입력 600토큰) |
|---|---|---|---|
| GPT-4.1-mini (2025-04-14) | 2024-06-01 | API, logprob·temperature 가능 | ≈ $35 |
| GPT-5-mini | 2024-05-31 | API, 추론 모델(temperature 미지원 가능) | ≈ $50–150 (추론 토큰에 따라) |
| Gemma 3 27B it | 2024-08 | vLLM, GPU 1장 | 약 수 시간 |
| Llama 3.3 70B (FP8) | 2023-12 | vLLM, GPU 1장(FP8 70GB, 짧은 컨텍스트) 또는 2장 | GPU 0 점유 상황 확인 필요 |
| o4-mini (선택) | 2024-06-01 | API | ≈ $100 |

- **N=20.** 파일럿에서 API 모델은 N=10, 로컬 8B는 N=50에서 지표가 포화했다. 27B 이상은 20이면 충분할 것으로 보되, F1에서 N=10/20/50 포화 여부를 다시 확인한다(한 번 50개를 뽑아 부분추출하면 추가 비용 없음).
- 추론 모델(GPT-5-mini)은 temperature를 못 바꾸므로 반복 추출 분산의 의미가 "추론 경로의 분산"이 된다. 논문에서 구분해 적는다.

## 5. 프롬프트와 조건
- **P-A (연속성):** EAAI prompt 4 그대로(최근 10일 종목·섹터·시장 수익률 + 메타데이터). 비미국은 섹터 수익률 대신 시장 수익률만.
- **P-B (풍부한 수치 맥락):** 60일 수익률 요약(평균·변동성·최대낙폭), 시장 대비 상대수익, 시가총액 순위. 텍스트 없이 할 수 있는 최대치. 텍스트 입력은 IJCAI 트랙에서만.
- Ω 변형: 경험적 / 상수 / shuffle / He–Litterman / Idzorek / 보정(walk-forward). 비교군: EW, 시가총액, MVO-126, 사전분포만, **모멘텀 BL(q = 과거 10일 평균)**, 상위 10 모멘텀, LLM 상위 10.
- 평가: 블록 부트스트랩 Sharpe 차이, 시장별·전체 풀링(시장 고정효과), 거래비용 {5, 10, 25}bp.

## 6. 단계와 go/no-go
| 단계 | 기한 | 내용 | 판정 |
|---|---|---|---|
| F0 | 10/13 | WRDS 로더(4시장, 시점 유니버스, 총수익률, rf), `blx` 동적 유니버스·walk-forward τ·모멘텀 baseline 확장 | 코드 검증(파일럿 재현) |
| F1 | 10/15 | 미국만, GPT-4.1-mini, P-A, N=10 → 2024-09~2025-12 (약 1,700 종목-시점, 17k 호출, ≈$5) | **go/no-go:** (a) q의 다음 기간 순위 상관이 모멘텀보다 높은가, (b) BL-경험적 Ω가 모멘텀 BL·EW를 부트스트랩에서 이기는가, (c) 경험적 Ω vs 상수 Ω 차이가 있는가. (b)·(c) 둘 다 아니면 F 트랙 중단 |
| F2 | 10/31 | 4시장 × 모델 3–4 × P-A/P-B, N=20 | 결과 표 확정 |
| F3 | 11월 | Financial Innovation 원고(EAAI 원고 재사용 가능 부분 + 리뷰 대응 전부). APC(오픈액세스 비용) 확인 필요 | 투고 |

- F1은 IJCAI 1단계 전에 끝난다. F0의 WRDS 로더와 동적 유니버스는 IJCAI 트랙도 그대로 쓴다(IJCAI는 2026년 구간을 yfinance로 이어 붙일지 F0 뒤 결정).

## 7. 사용자 결정 요청
1. F1 비용(≈$5)과 OpenAI 키 사용 승인. 키는 `.env`에 넣어 주시면 된다.
2. 로컬 모델 실행을 위한 GPU: GPU 1(76GB 사용 중, 다른 세션)·GPU 0(다른 실험) 상황을 알려 주시거나 사용 가능한 시간대를 지정.
3. F 트랙의 저자 구성·Financial Innovation APC 처리(교신저자와 상의 필요).

## 가이드 점검
- **한 문장 주장(F 트랙, 조건부):** 시점 기준 유니버스와 4개 시장에서, LLM 반복 추출 분산을 BL view 불확실성으로 쓰면 같은 view를 관행적 Ω와 결합할 때보다 배분이 낫다.
- 원칙 1(문제부터): 파일럿의 실패(모멘텀, 과신)를 출발점으로 삼음 → 충족. 원칙 3(관점): 금융 저널 기준으로는 "다중 시장·시점 유니버스·Ω ablation"이 EAAI 대비 새로움이지만 관점의 새로움은 약함 → 부분 충족(저널 선택의 근거). 원칙 4: 모멘텀 baseline과 Ω ablation이 주장을 직접 검증하도록 설계 → 설계 수준 충족. 원칙 5: 시점 유니버스·문서화 컷오프·총수익률 → 충족. 원칙 6: F1 no-go 기준을 미리 정함 → 충족. 원칙 7: 미실행.
- 세 질문: 주장은 조건부 초안. F1의 (a)(b)(c)가 그대로 검증. 회의적 독자(금융 리뷰어)는 "16개월"을 지적할 것 → 4개 시장 풀링으로 대응하되 한계로 명시.
